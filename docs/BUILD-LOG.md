## Что использовали

Windows и PowerShell, Codex для ведения проекта и подготовки кода/документации, Python, pyserial 3.5, esptool 5.6.0, PlatformIO 6.2.0, espressif32 6.12.0, ESP-IDF 5.5.0. Для анализа записи — стандартная библиотека Python и независимая сверка FFT через NumPy 2.2.6. Для поиска компонентов — Ozon, браузер, Docker Desktop и ozon-customer-mcp. Для механики уже есть LEGO-совместимые детали и FlashForge AD5X; напечатанные детали пока не задокументированы.

Полные результаты, неудачные попытки и ограничения сохранены в [ASSEMBLY.md](../ASSEMBLY.md). Публичный журнал описывает работу с оборудованием, а не дословные личные переписки. Фактическую сумму оплаты ещё нужно сверить с обезличенным чеком.
