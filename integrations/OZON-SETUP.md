# Поиск компонентов через Ozon MCP

15 ноября 2026 использован сторонний проект
[Raleose/ozon-customer-mcp](https://github.com/Raleose/ozon-customer-mcp),
ревизия `d6bc52e37b98f423d6f5c611a038778179db3f53`.
Запускался в Docker через stdio, без публикации портов, подключения аккаунта
или тома браузерного профиля. Для выбора корзины использовался также браузер.

Исходный npm audit показал 9 проблем: 2 moderate, 6 high, 1 critical.
В локальном производном образе зависимости обновляли; тогда npm audit
сообщил 0 известных проблем. Это исторический результат, не текущая
проверка и не аудит Python, браузера или системных пакетов.

Обнаружение 19 MCP-инструментов проверено. Первый поиск получил HTTP 403,
повторный позднее вернул товары; причина изменения не установлена.
Анонимная сессия MCP не синхронизируется с корзиной авторизованного браузера.
Найденные цены представлены в ORDER.md с датой и ограничениями.

Локальный clone, Dockerfile с незакреплёнными обновлениями, результаты поиска
и клиентские скрипты с параметрами доставки исключены из публичного Git.
Для повторного использования потребуется отдельный аудит актуальных
зависимостей. Не передавайте стороннему инструменту пользовательские cookies.
