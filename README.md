# arduCat

Домашний робот на LEGO-совместимой механике и ESP32-S3. Рабочее название на ранних этапах — ArduBot. Цель: разговор, движение к видимой метке и перевозка небольших предметов. Бюджет первого прототипа — до 15 000 ₽ на покупные компоненты.

Это стендовый прототип. Движение, портал, камера и автономная навигация пока не реализованы. Моторы не подключены. Два контроллера разделяют голос и движение, чтобы будущая остановка не зависела от ИИ.

## Что уже работает

- Запись речи: ESP32-S3 N16R8 + I2S-микрофон, PCM16 mono 16 kHz, 3 секунды по UART-команде.
- Воспроизведение: MAX98357A + динамик 4 Ом 3 Вт, I2S stereo TX32. Речь разборчива на умеренной амплитуде; дребезг динамика остаётся открытой проблемой.
- Два VL53L0X проверены по одному. Вторая плата датчика показала около 158 мм при мишени 150 мм и 304 мм при 300 мм. Текущая v3 непрерывно запускает одиночные измерения; динамические испытания ещё впереди.
